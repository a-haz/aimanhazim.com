# Images for the Build Log

Drop screenshots / photos here (e.g. `isaac-sim-world.jpg`), then reference them
from `assets/js/progress.js`:

```js
images: ["/assets/img/isaac-sim-world.jpg", "/assets/img/lidar-scan.png"],
```

Tips:
- Use `.jpg` for photos/screenshots, `.png` for diagrams, `.webp` for the smallest files.
- Keep them reasonably sized (≤ ~1600px wide) so the page stays fast.
- The filename becomes part of the public URL, so avoid spaces — use `dashes-like-this.jpg`.
